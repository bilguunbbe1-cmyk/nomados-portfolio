# NomadOS — тал нутгийн үйлдлийн систем хэлбэртэй портфолио

> SWE334 · Интернэт программчлал · Бие даалт 2

**Live:** https://ТАНЫ-САЙТ.vercel.app  ← байршуулсны дараа солиорой

Ердийн «нэг хуудас scroll»-той портфолио биш — зочин **NomadOS** гэдэг жижигхэн үйлдлийн системийг асааж, цонх нээж, терминалд команд бичиж, бүр шагай орхиж намайг танина.

---

## Бүтээлч санаа

| Санаа | Хэрхэн хэрэгжүүлсэн |
|---|---|
| **Үйлдлийн систем маягийн интерфэйс** | Цонх чирэх, багасгах, томруулах, хэмжээ өөрчлөх, taskbar, Start цэс, баруун товчны цэс — бүгд `js/windows.js`, `js/main.js`-д гараар бичсэн |
| **Кодоор зурсан ханын зураг** | Тэнгэр, нар/сар, од, үүл, шувуу, уулс, **Монгол гэр** — бүгд SVG код (`js/scene.js`). Зураг файл огт ашиглаагүй |
| **Улаанбаатарын цагтай амьд тал нутаг** | Ханын зураг Улаанбаатарын цагаар үүр → өдөр → үдэш → шөнө болж, нар нумын дагуу хөдөлнө. Шөнө гэрийн хаалганаас гэрэл тусна |
| **Parallax** | Хулгана хөдлөхөд уулс өөр өөр хурдаар шилжиж гүн мэдрэмж өгнө |
| **Терминал** | `help`, `about`, `skills`, `projects`, `open 1`, `neofetch`, `shagai` … Монгол alias (`тусламж`, `бүтээл`), Tab-аар гүйцээх, ↑/↓ түүх |
| **Шагай тоглоом** | Монголын уламжлалт тоглоом — 4 шагай орхиж азаа үзнэ |
| **Апп бүр өөрийн дүртэй** | «Миний тухай» = Notepad, «Ур чадвар» = Систем монитор (шууд график), «Холбоо барих» = Шуудангийн апп, «Бүтээлүүд» = File explorer |
| **Кодоор үүсгэсэн дуу** | Web Audio API — Монгол ардын аялгууны **пентатоник гамм**-аар асаах дуу. Аудио файл ашиглаагүй |
| **6 нууц (easter egg)** | Олдсон тоо taskbar дээр харагдана (доор spoiler бий) |
| **2 хэл, 2 горим** | Монгол / English, цайвар / бараан |
| **Responsive** | Утсан дээр desktop нь **утасны home screen** болж, цонх бүр бүтэн дэлгэцийн апп болж нээгдэнэ |

## Заавал байх 5 зүйл

1. **Танилцуулга** — Асаах дэлгэц болон desktop-ын нүүрэнд нэр, чиглэл, нэг өгүүлбэр
2. **Миний тухай ба ур чадвар** — «Миний тухай.txt» болон «Ур чадвар» аппууд
3. **Бүтээлүүд (4)** — «Бүтээлүүд» хавтас: зураг, тайлбар, Демо / GitHub холбоос
4. **Холбоо барих** — Имэйл, GitHub, LinkedIn, Instagram + имэйл бичих форм
5. **Responsive ба байршуулалт** — 760px-ээс доош утасны горим; Vercel дээр байршсан

## Ашигласан технологи

- **HTML5, CSS3, Vanilla JavaScript** — framework, library, бэлэн загвар ашиглаагүй
- **SVG** — ханын зураг, icon, лого, бүтээлийн placeholder зураг
- **Web Audio API** — дуу; **Pointer Events** — цонх чирэх (хулгана + хуруу); **localStorage** — тохиргоо хадгалах
- **Google Fonts** — Unbounded, Inter, JetBrains Mono
- **Vercel** — байршуулалт

## Файлын бүтэц

```
index.html          — бүтэц (boot дэлгэц, desktop, taskbar)
data.js             — ★ ХУВИЙН МЭДЭЭЛЭЛ — зөвхөн үүнийг засахад хангалттай
css/style.css       — бүх загвар (өнгөний хувьсагч, апп бүр, гар утас)
js/i18n.js          — Монгол / English текстүүд
js/core.js          — туслах хэрэгсэл: хадгалалт, дуу, мэдэгдэл, нууцууд
js/scene.js         — SVG ханын зураг, цагаар өөрчлөгдөх тэнгэр
js/apps.js          — аппуудын агуулга (Миний тухай, Ур чадвар, Бүтээлүүд …)
js/terminal.js      — терминалын командууд
js/windows.js       — цонх удирдагч (нээх, хаах, чирэх, taskbar)
js/main.js          — асаах, Start цэс, хэл/горим, Konami код
assets/             — лого, бүтээлийн зургууд
```

## Ажиллуулах

Build хийх шаардлагагүй. `index.html`-ийг VS Code-ийн **Live Server**-ээр нээхэд л болно.
